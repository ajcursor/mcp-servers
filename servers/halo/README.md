# halo MCP server

HALO change management for the Comms Bot.

| Tool | Access | What it does |
|---|---|---|
| `create_change_record` | Write · needs ops approval | Log a change record: title, summary, and every action with the bot that did it and who approved it |

Env: `HALO_API_URL`, `HALO_API_TOKEN` (service account `svc-grokbot-halo`), `PORT` (4204).
